## ✨ Features & Architecture

* **Luxury Editorial Design**: Tailored architectural aesthetics using a Deep Charcoal (`#15191D`), Warm Ivory (`#F7F5F0`), and Architectural Gold (`#C49A45`) palette.
* **Hero Section**: Full-screen photorealistic architectural imagery with subtle parallax, editorial typography, and interactive CTAs.
* **About Us**: Comprehensive two-column layout highlighting thoughtful planning, structural quality, and 24-hour service commitment.
* **Services Directory**: Proposed services with dedicated WhatsApp inquiry links and quote modal triggers:
  * Residential Construction
  * Commercial Construction
  * Architectural Planning
  * Interior Design
  * Building Renovation
  * Project Consultation
* **Demonstration Portfolio**: Filterable architectural concepts with interactive preview modals.
* **Why Choose Us**: 4 core engineering and execution pillars.
* **Complete WhatsApp Integration**:
  * Floating WhatsApp button with subtle pulse animation and status dot.
  * Direct quote request form with client-side validation that compiles and opens a pre-formatted WhatsApp message without storing data.
* **Contact & Map**: Complete business credentials and Google Maps embed for Tamkuhi Raj, Kushinagar.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
